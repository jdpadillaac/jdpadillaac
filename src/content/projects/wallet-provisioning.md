## Objetivo

Abstraer la complejidad del SDK Thales D1 detrás de una API Dart clara para apps Flutter que implementan wallet digital.

## Enfoque

El paquete concentra puentes nativos, configuración y puntos de extensión documentados para que el equipo de producto no replique integraciones frágiles en cada app.

## Valor

Reduce tiempo de integración y centraliza el conocimiento de provisioning en un solo artefacto versionable.
